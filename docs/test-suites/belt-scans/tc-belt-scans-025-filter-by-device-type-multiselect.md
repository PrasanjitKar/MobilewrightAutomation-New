## 🎯 Objective

Verify that selecting one or more Monitoring Device Types (e.g. `CordProtect`, `MultiProtect`) in the filter modal filters the list to records matching those device types.

---

## ✅ Preconditions

- Belt scan records generated by various hardware device types exist

---

## 🔢 Test Steps

| # | Action | Expected Result |
|---|--------|----------------|
| 1 | Open Filter modal and tap "Monitoring Device Type" | Multiselect list of distinct device types opens |
| 2 | Select "CordProtect" and tap Apply in popup | Device type is selected |
| 3 | Tap "Save" in filter modal | Filter executes |
| 4 | Inspect list screen | All displayed rows have `deviceType == 'CordProtect'` |

---

## 🏁 Expected Results

- Scans are filtered accurately by diagnostic hardware classification
