# TC-COVER-WEAR-021: Missing PDF Report SnackBar Notification

> **Suite**: `cover-wear` | **Priority**: `Low` | **Type**: `Regression` | **Platforms**: `@both` (Android, iOS)  
> **Source Spec**: `lib/src/features/coverwear/presentation/widgets/cover_wear_row.dart` (`_openPdfPreview`)

---

## 🎯 Objective
Verify that tapping the grey disabled PDF icon (`ContiPlusIcon.pdfGrey_20x20`) on an event where `reportUrl` is null or empty displays a feedback `SnackBar` informing the user that the PDF report has not been generated yet (`appLocalizations.pdfReportNotGenerated`).

---

## 📋 Preconditions
- An event exists where `reportUrl` is null (report is not yet generated by server).

---

## 🧪 Test Steps
1. Navigate to `CoverWearListPage`.
2. Locate an event with the grey PDF icon (`ContiPlusIcon.pdfGrey_20x20`).
3. Tap on the grey PDF icon.
4. Verify that navigation to preview screen is aborted.
5. Verify that a `SnackBar` is displayed with:
   - Background color: `ContiplusColors.continentalLightRed`.
   - Content: `AppLocalizations.of(context)!.pdfReportNotGenerated` ("PDF report not generated").

---

## 🔍 Expected Results
- User receives instant, non-disruptive feedback when a report is not available.

---

## 📱 Flutter Source Reference
- **Widget**: `lib/src/features/coverwear/presentation/widgets/cover_wear_row.dart` (`_openPdfPreview`)
- **i18n Key**: `AppLocalizations.of(context)!.pdfReportNotGenerated`
