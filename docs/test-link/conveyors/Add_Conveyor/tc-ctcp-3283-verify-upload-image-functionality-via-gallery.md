## Test Steps

| Step | Action | Expected Result |
|---|---|---|
| 1 | Precondition | User is on Add conveyor page |
| 2 | Click on image icon | On click, following options should display: Gallery, Camera |
| 3 | Click on gallery | On click phone gallery should open |
| 4 | Select the image from phone gallery | On selecting the image, it should land to Add conveyor screen with the same image displayed in conveyor profile |
| 5 | Click on save button | The image should get saved |
| 6 | Verify conveyor profile image gets updated | The profile image of conveyor should get updated with the same image |
