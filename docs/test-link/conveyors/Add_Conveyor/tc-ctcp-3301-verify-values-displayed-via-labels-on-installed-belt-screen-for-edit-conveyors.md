# CTCP-3301 — Verify values displayed via labels on installed belt screen for Edit conveyors

| Field | Value |
|---|---|
| **TC ID** | CTCP-3301 |
| **Suite** | Conveyors → Add_Conveyor |
| **Name** | Verify values displayed via labels on installed belt screen for Edit conveyors |
| **Priority** | High |
| **Execution Type** | Manual |
| **Status** | 📋 Planned |

## Test Steps

| Step | Action | Expected Result |
|---|---|---|
| 1 | Precondition | User is on Edit conveyor page |
| 2 | Navigate to installed belt screen | User should able to navigate |
| 3 | Look for labels displayed in flow chart | Following fields should display in flow chart with values if fields are filled: Belt construction, Belt width, Belt breaking strength, Top cover thickness, Bottom cover thickness, Top cover compound, Bottom cover compound |
| 4 | Edit some of the values | User should able to edit the values in flow chart by changing the field values |
| 5 | Click on Save and close button | The fields should get updated with new values |
| 6 | Navigate to conveyor details page | User should able to navigate |
| 7 | Look for flow chart again in installed belt | The flow chart should display with updated values |

**Requirements:** None
