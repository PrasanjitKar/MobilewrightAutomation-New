## Test Steps

| Step | Action | Expected Result |
|---|---|---|
| 1 | Precondition | User is on conveyor list page |
| 2 | Look for the conveyor which needs to be edited | The conveyor should display in list |
| 3 | Click on three dots displayed in conveyor entry | On click, two options should display: Edit, Delete |
| 4 | Click on Edit option | On click user should land to edit page of that conveyor |
| 5 | Edit the details of conveyor | User should able to edit the details of conveyor |
| 6 | Click on Save button | On click, new details should get updated and user should land to conveyor list page |
| 7 | Verify updated details | Navigate to conveyor details page and verify the updated details |
