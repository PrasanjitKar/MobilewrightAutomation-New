## Test Steps

| Step | Action | Expected Result |
|---|---|---|
| 1 | Based on precondition data download inspection Multi inspect | User should able to download the inspection event |
| 2 | Look for the file name of the pdf report | The pdf report should generate with name :<br>Inspection date(2025-01-21-)+Sitename(testVMCSIte@9)+Inspection event name(Multiple-21. Jan, 2025 testVMCSIte@9) egg :2025-01-21-testVMCSIte@9-Multiple-21. Jan, 2025 testVMCSIte@9 |
| 3 | Look for heading displayed on the top of pdf report | The pdf report should display inspection event name : 21. Jan, 2025 testVMCSIte@9 |
| 4 | Look for generated date | Generated date should display the date PDF report is generated egg :Generated Date: Jan 23, 2025 |
| 5 | Look for generated by | Generated by should display the name of user who downloaded the report |
| 6 | Look for inspection table | Inspection table should display :<br>-Inspection date, Site & Inspector in data |
| 7 | Look for data displayed in overview graph | The overview graph should display : Total, Critical, Fault & Good card with respective item count<br>To be completed will also be reflected with respective color of conditions |
| 8 | Look for condition and status count table | Following column should display :<br>1. Conveyor name CV1<br>2. Critical column with Completed and To be completed count<br>3. fault column with Completed and To be completed count<br>4. Good column with Completed and To be completed count<br>The count should in table should match with inspection event details count |
| 9 | Look for items displayed for respective conveyor inspections | respective conveyor should display the following details :<br>Inspections-CV1<br>Table [ Belt width, Belt carcass, Belt Rating, Top & Bottom cover thickness ] |
| 10 | Look for details displayed for each inspection item | Following details should show :<br>Conveyor name, Asset, Detail, Recommendation, Observation, Status & Condition<br>If any image is uploaded with item it should also display |
| 11 | Look for Conveyor inspection item display sequence in report | The order sequence should be same as it displays in front end event details page |
| 12 | Look for the data displayed in footer of the page | Footer of the pdf page should display :<br>- Continental AG 2025. All Rights Reserved.<br>-Pagination entry |
