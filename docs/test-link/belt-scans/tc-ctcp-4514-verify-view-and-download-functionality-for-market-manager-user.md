**Summary:** Verify the view and download functionality for Market Manager user

**Preconditions:** User is logged in as Market Manager user

## Test Steps

| Step | Action | Expected Result |
|---|---|---|
| 1 | Verify user click on Belt Scan Record card from home level | Belt Scan Record list page should be displayed |
| 2 | Verify Belt scan record in the list | Belt scan record with assigned market for the Market Manager user should be displayed |
| 3 | Verify user is allowed to view Belt Scan Record from the list from home level | View Belt Scan PDF is allowed for Market Manager user |
| 4 | Verify user is allowed to download the Belt Scan PDF | Download Belt Scan PDF is allowed for Market Manager user |
