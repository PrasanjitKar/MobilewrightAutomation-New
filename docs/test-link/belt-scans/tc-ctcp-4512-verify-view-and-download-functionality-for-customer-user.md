**Summary:** Verify the view and download functionality for Customer user

**Preconditions:** User is logged in as customer user

## Test Steps

| Step | Action | Expected Result |
|---|---|---|
| 1 | Verify user click on Belt Scan Record card from home level | Belt Scan list page should be displayed |
| 2 | Verify Belt scan record in the list | Belt scan record with assigned site for the customer user should be displayed |
| 3 | Verify user is allowed to view Belt Scan Record from the list from home level | View Belt Scan Record is allowed for customer user |
| 4 | Verify user is allowed to download the Belt Scan PDF | Download Belt Scan PDF is allowed for customer user |
