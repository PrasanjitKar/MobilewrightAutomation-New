# CTCP-4506 — Verify User is able to View "Belt Scan" Card

| Field | Value |
|---|---|
| **TC ID** | CTCP-4506 |
| **Suite** | Belt Scan |
| **Name** | Verify User is able to View "Belt Scan ." Card |
| **Priority** | High |
| **Execution Type** | Manual |
| **Status** | 📋 Planned |

**Summary:** Verify User is able to View "Belt Scan/Cord Inspect" Card

**Preconditions:** User is on Home page provided user is given permission to view the Belt Scan/Cord Inspect

## Test Steps

| Step | Action | Expected Result |
|---|---|---|
| 1 | Verify user is login to Mobile application as Customer user | User should be on home page |
| 2 | Verify User is displayed with Belt Scan Card on home level | Belt Scan card on home level should be displayed. |
| 3 | Verify both web and mobile Belt Scan card count should be in sync | Belt Scan card count that is displayed on web should display the same count on the mobile in home page |
| 4 | Verify user view a conveyor and check Belt Scan card displayed | Belt Scan card should be displayed on Conveyor level |
| 5 | Verify user view a conveyor which has Belt Scan | Belt Scan card count that is displayed on web conveyor level should display the same count on the mobile in conveyor level. |

**Requirements:** CTCP-13276, CTCP-13277: Belt Scan Home Level, Conveyor level, View and Download
