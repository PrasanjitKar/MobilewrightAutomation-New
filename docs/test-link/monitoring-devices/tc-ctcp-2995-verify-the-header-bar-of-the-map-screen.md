# CTCP-2995 — Verify the Header bar of the Map screen.

| Field | Value |
|---|---|
| **TC ID** | CTCP-2995 |
| **Suite** | Monitoring Devices |
| **Name** | Verify the Header bar of the Map screen. |
| **Priority** | High |
| **Execution Type** | Manual |
| **Status** | 📋 Planned |

**Summary:** Verify the Header bar of the Map screen.

**Preconditions:** User is on Home page.

## Test Steps

| Step | Action | Expected Result |
|---|---|---|
| 1 | Pre condition | User is on Home page. |
| 2 | Verify the 'Monitoring Devices' card is visible on the Home page. | User is able to see the 'Monitoring Devices' card on the Home page. |
| 3 | Click on the 'Monitoring Devices' card is visible on the Home page. | User is navigated to Monitoring Devices list page. |
| 4 | Click on the 'Monitoring Device Location' pin which is visible for particular Device. | User is navigated to Map screen and able to see H, T and Monitoring Device pin (if available). |
| 5 | Verify the Header bar of the Map screen. | Header bar contains the below values-<br>- <-- (back button)<br>- Device name<br>- Bell icon.(N/A)<br>- Vertical 3 dots.(N/A) |
