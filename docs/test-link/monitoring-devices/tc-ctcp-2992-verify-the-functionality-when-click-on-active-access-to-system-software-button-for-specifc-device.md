# CTCP-2992 — Verify the functionality when click on Active 'Access to System Software' button for specifc Device

| Field | Value |
|---|---|
| **TC ID** | CTCP-2992 |
| **Suite** | Monitoring Devices |
| **Name** | Verify the functionality when click on Active 'Access to System Software' button for specifc Device |
| **Priority** | High |
| **Execution Type** | Manual |
| **Status** | 📋 Planned |

**Summary:** Verify the functionality when click on Active 'Access to System Software' button for specifc Device under Devices list page.

**Preconditions:** User is on Home page.

## Test Steps

| Step | Action | Expected Result |
|---|---|---|
| 1 | Pre condition | User is on Home page. |
| 2 | Verify the 'Monitoring Devices' card is visible on the Home page. | User is able to see the 'Monitoring Devices' card on the Home page. |
| 3 | Click on the 'Monitoring Devices' card is visible on the Home page. | User is navigated to Monitoring Devices list page. |
| 4 | Verify the visibility of 'Access to System Software'<br>link for specific Device when user is provided http or www. url under 'Access to System Software' while creation. | User could see the button is activated. |
| 5 | Verify the functionality when click on Active 'Access to System Software' button for specifc Device under Devices list page. | Default browser will be opened with the url is given under 'Access to System Software' field while creation of device. |
