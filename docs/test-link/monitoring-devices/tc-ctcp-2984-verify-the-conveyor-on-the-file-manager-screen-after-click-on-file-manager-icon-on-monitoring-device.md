# CTCP-2984 — Verify the Conveyor on the File Manager screen after click on File Manager icon on Monitoring Device

| Field | Value |
|---|---|
| **TC ID** | CTCP-2984 |
| **Suite** | Monitoring Devices |
| **Name** | Verify the Conveyor on the File Manager screen after click on File Manager icon on Monitoring Device |
| **Priority** | High |
| **Execution Type** | Manual |
| **Status** | 📋 Planned |

**Summary:** Verify the Conveyor on the File Manager screen after click on File Manager icon on Monitoring Devices list page for specific Device.

**Preconditions:** User is on Home page.

## Test Steps

| Step | Action | Expected Result |
|---|---|---|
| 1 | Pre condition | User is on Home page. |
| 2 | Verify the 'Monitoring Devices' card is visible on the Home page. | User is able to see the 'Monitoring Devices' card on the Home page. |
| 3 | Click on the 'Monitoring Devices' card is visible on the Home page. | User is navigated to Monitoring Devices list page. |
| 4 | Click on 'File Manager' folder for specific Device under Device list page and Verify the functionality. | User is navigated to File Manager of associated conveyor. |
| 5 | Verify the Conveyor on the File Manager screen is related to associated device. | User could see the Conveyor name is assiciated to particular Device. |

**Requirements:** None
