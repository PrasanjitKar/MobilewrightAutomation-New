# CTCP-2978 — Verify the Tab bar at bottom of the Device list page.

| Field | Value |
|---|---|
| **TC ID** | CTCP-2978 |
| **Suite** | Monitoring Devices |
| **Name** | Verify the Tab bar at bottom of the Device list page. |
| **Priority** | High |
| **Execution Type** | Manual |
| **Status** | 📋 Planned |

**Summary:** Verify the Tab bar at bottom of the Device list page.

**Preconditions:** User is on Home page.

## Test Steps

| Step | Action | Expected Result |
|---|---|---|
| 1 | Pre condition | User is on Home page. |
| 2 | Verify the 'Monitoring Devices' card is visible on the Home page. | User is able to see the 'Monitoring Devices' card on the Home page. |
| 3 | Click on the 'Monitoring Devices' card is visible on the Home page. | User is navigated to Monitoring Devices list page. |
| 4 | Verify the Visibility of Tab bar at bottom of the Device list page (Means button like Home, Conveyor, Corporates, Free Tools and Inspections) - N/A in listing screen, only on home screen | User is Not able to see the Tab bar at the bottom of the page. |
