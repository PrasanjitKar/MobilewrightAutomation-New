# CTCP-2987 — Verify the latest created device is visible at the top under 'Monitoring Devices' folder under File

| Field | Value |
|---|---|
| **TC ID** | CTCP-2987 |
| **Suite** | Monitoring Devices |
| **Name** | Verify the latest created device is visible at the top under 'Monitoring Devices' folder under File |
| **Priority** | High |
| **Execution Type** | Manual |
| **Status** | 📋 Planned |

**Summary:** Verify the latest created device is visible at the top under 'Monitoring Devices' folder under File Manager screen.

**Preconditions:** User is on Home page.

## Test Steps

| Step | Action | Expected Result |
|---|---|---|
| 1 | Pre condition | User is on Home page. |
| 2 | Verify the 'Monitoring Devices' card is visible on the Home page. | User is able to see the 'Monitoring Devices' card on the Home page. |
| 3 | Click on the 'Monitoring Devices' card is visible on the Home page. | User is navigated to Monitoring Devices list page. |
| 4 | Click on the 'File Manager' folder of specific device which is having multiple devices under same Conveyor. | User is navigated to File Manager of associated conveyor. |
| 5 | Verify the latest created device is visible at the top under 'Monitoring Devices' folder under File Manager screen. | User could see recently created device under specific conveyor should be visible at top under 'Monitoring Devices' folder under 'File Manager' Screen. |

**Requirements:** None
