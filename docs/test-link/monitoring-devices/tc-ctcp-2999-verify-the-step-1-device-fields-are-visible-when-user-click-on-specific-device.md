# CTCP-2999 — Verify the Step "1" Device fields are visible when user click on specific Device.

| Field | Value |
|---|---|
| **TC ID** | CTCP-2999 |
| **Suite** | Monitoring Devices |
| **Name** | Verify the Step "1" Device fields are visible when user click on specific Device. |
| **Priority** | High |
| **Execution Type** | Manual |
| **Status** | 📋 Planned |

**Summary:** Verify the Step "1" Device fields are visible when user click on specific Device.

**Preconditions:** User is on Home page.

## Test Steps

| Step | Action | Expected Result |
|---|---|---|
| 1 | Pre condition | User is on Home page. |
| 2 | Verify the 'Monitoring Devices' card is visible on the Home page. | User is able to see the 'Monitoring Devices' card on the Home page. |
| 3 | Click on the 'Monitoring Devices' card is visible on the Home page. | User is navigated to Monitoring Devices list page. |
| 4 | Click on any specific Device and verify the Step "1" Device fields are visible on the page. | User could see the following details related to my Monitoring Device, when I click on it:<br>Device Name<br>Device Type<br>(Load Sense / Multi Protect / Cord Protect / Rip Protect / Other)<br>Brand<br>Serial Number<br>Firmware version<br>Remote Connection<br>(3G/4G router / Local only / VPN through mine site)<br>Installation Date<br>Commissioning Date<br>Last Service Date<br>Access To System Software<br>Belt/Conveyor saves<br>Status<br>(Running / Not in Operation / Prior to Commissioning) |
