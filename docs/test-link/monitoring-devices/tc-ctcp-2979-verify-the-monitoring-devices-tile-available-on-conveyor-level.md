**Summary:** Verify the Monitoring Devices tile available on Conveyor Level.

## Test Steps

| Step | Action | Expected Result |
|---|---|---|
| 1 | Pre condition | User is on Home page. |
| 2 | Click on the Conveyors tile and open any specific conveyor which is having Monitoring Devices. | User is able to open the Conveyor. |

| 5 | Verify user checks sequence of the devices that belong to conveyor in the conveyor level | Mobile Device list Sequence should match as it is displayed on web Device list on conveyor level |
