# CTCP-2982 — Verify the "Monitoring Devices" folder is created automatically in the File Manager page after creat

| Field | Value |
|---|---|
| **TC ID** | CTCP-2982 |
| **Suite** | Monitoring Devices |
| **Name** | Verify the "Monitoring Devices" folder is created automatically in the File Manager page after creat |
| **Priority** | High |
| **Execution Type** | Manual |
| **Status** | 📋 Planned |

**Summary:** Verify the "Monitoring Devices" folder is created automatically in the File Manager page after creation of Monitoring Device.

**Preconditions:** User is on Home page.

## Test Steps

| Step | Action | Expected Result |
|---|---|---|
| 1 | Pre condition | User is on Home page. |
| 2 | Verify the 'Monitoring Devices' card is visible on the Home page. | User is able to see the 'Monitoring Devices' card on the Home page. |
| 3 | Click on the 'Monitoring Devices' card is visible on the Home page. | User is navigated to Monitoring Devices list page. |
| 4 | Click on 'File Manager' folder for specific Device under Device list page and Verify the functionality. | User is navigated to File Manager of associated conveyor. |
| 5 | Verify the "Monitoring Devices" folder is created automatically in the File Manager page. | User could see the "Monitoring Devices" folder is created automatically in the File Manager page. |

**Requirements:** None
