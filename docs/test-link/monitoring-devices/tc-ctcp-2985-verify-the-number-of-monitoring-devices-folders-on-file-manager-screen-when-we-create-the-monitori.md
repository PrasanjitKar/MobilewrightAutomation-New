# CTCP-2985 — Verify the number of "Monitoring Devices" folders on File Manager screen when we create the Monitori

| Field | Value |
|---|---|
| **TC ID** | CTCP-2985 |
| **Suite** | Monitoring Devices |
| **Name** | Verify the number of "Monitoring Devices" folders on File Manager screen when we create the Monitori |
| **Priority** | High |
| **Execution Type** | Manual |
| **Status** | 📋 Planned |

**Summary:** Verify the number of "Monitoring Devices" folders on File Manager screen when we create the Monitoring device again with new device name on the same conveyor.

**Preconditions:** User is on Home page.

## Test Steps

| Step | Action | Expected Result |
|---|---|---|
| 1 | Pre condition | User is on Home page. |
| 2 | Verify the 'Monitoring Devices' card is visible on the Home page. | User is able to see the 'Monitoring Devices' card on the Home page. |
| 3 | Click on the 'Monitoring Devices' card is visible on the Home page. | User is navigated to Monitoring Devices list page. |
| 4 | Click on the 'File Manager' folder of specific device which is having new Device name on the same existing Conveyor (Means for this conveyor already Device is created). | User is navigated to File Manager of associated conveyor. |
| 5 | Verify the number of "Monitoring Devices" folders on File Manager screen when we create the Monitoring device again with new device name on the same conveyor. | User could see only one "Monitoring Devices" folder under 'File Manager' screen even if we create multiple monitoring devices on the same conveyor. |

**Requirements:** None

**Keywords:** Regression
