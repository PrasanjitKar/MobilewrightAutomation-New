## Test Steps

| Step | Action | Expected Result |
|---|---|---|
| 1 | Precondition : | User is add site/shop |

| 3 | Click on profile image | On click pop-up should display in footer :<br>-Camera <br>-Gallery |

| 5 | Capture image | User should able to capture image with following options :<br>-Cross button(On click should land to add site screen)<br>-Tick mark(on Click image should upload)<br>- Return symbol(On click current image should get removed and camera opens again to take new picture) |
| 6 | Click on Tick option | On click image should get save and user should redirect to add corporate screen |
